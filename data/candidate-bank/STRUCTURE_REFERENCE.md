# PDF 候選題型／結構參考

本文件依 PDF 逐頁視覺檢視整理，**不是已核准題目資料**。原始 PDF 中文文字抽取為亂碼，
因此所有 122 題仍為 `needs-review`，不得提供給學生。

| 大項 | 目視可辨識題型 | 建議對應與審核重點 |
|---|---|---|
| 第1單元 | 最大公因數、最小公倍數、共同週期、等分分組、短除法 | 對應 unit1 各主題；檢查「最多組」與「每組數量」是否問對未知量 |
| 第2單元 | 分數除法直接計算、帶分數、等分、包含除、反推被除數 | 對應 unit2；生活題問「幾份」時必須是整數或明確說可含不足一份 |
| 第3單元 | 方程式、數列／圖形規律、和差積商不變、間隔問題 | 對應 unit3；每一步必須服務同一數量關係 |
| 第4單元 | 小數除法、估商、小數點、平均分配、反推除數 | 對應 unit4；確認小數精度與單位 |
| 第5單元 | 比的記法、比值、相等比、最簡整數比、比例應用 | 對應 unit5；比與比值不可混用 |
| 複習（一） | 第1～5單元綜合計算與應用 | 先依核心 operation 分流到 review1 對應主題，不以「綜合」掩蓋分類 |
| 第6單元 | 圓周率、圓周長、弧長、扇形周長、反推半徑 | 對應 unit6；π 取值與單位需完整 |
| 第7單元 | 圓面積、扇形／半圓面積、組合圖形 | 對應 unit7；區分長度與平方單位 |
| 第8單元 | 速率、距離、時間、平均速率、時分秒換算 | 對應 unit8；平均速率須以總距離除以總時間 |
| 第9單元 | 放大縮小、比例尺、圖上／實際距離、面積倍率 | 對應 unit9；長度倍率與面積倍率不可混淆 |
| 複習（二） | 圓、速率、比例尺及六上綜合應用 | 對應 review2；逐題標記 operationKey、cognitiveMode、solutionSteps |

## 正式納入前逐題必要欄位

- 現有 payload：`id/stageId/unitId/difficulty/concept/type/prompt/answer/hint/explanation/choices?`
- 來源：`source/sourceTitle/license/status/originalCandidateId/reviewStatus`
- 結構：`operationKey/cognitiveMode/solutionSteps`
- 驗證：答案重新計算、選擇題唯一數學正解、單位完整、主詞一致、無答案洩漏、
  所有步驟服務核心概念、不得與現有結構指紋重複。
