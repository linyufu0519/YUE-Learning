  六年級數學學習站 — 錯題複習與星星顯示調整 變更摘要
  日期：2026-09-22
================================================================================

【USER 需求】
  新增學生可操作的錯題複習入口，讓康軒版與翰林版的錯題可選擇單題或
  整份重新作答。答對後必須移出錯題本並完成「修正錯題」任務；答錯則
  更新最新紀錄並保留。錯題本為空時需有清楚提示。

  星星欄位、累加及雲端合併邏輯需完整保留，但首頁、教學／練習頁、
  家長頁與等級獎品視窗均不得再顯示星星數字、圖示或文案。

--------------------------------------------------------------------------------

【影響範圍】

  程式位置一：index.html、js/home.js、css/styles.css
  函式／區塊：首頁錯題複習入口與 renderWrongReviewEntry
  說明：依目前教材版本顯示待複習題數及可到達的學生入口。
  異動：新增「錯題複習」卡片；有錯題時顯示數量，無錯題時顯示完成提示。

  修改前：
    首頁沒有學生端錯題本入口。

  修改後：
    <a id="wrong-review-btn" href="practice.html?review=wrong">
      查看錯題並重新作答
    </a>

  ─────────────────────────────────────────────────────────────────────────────

  程式位置二：js/practice.js、js/wrong-review.js、js/question-engine.js
  函式／區塊：setupWrongReview、renderWrongReviewList、startWrongReview、

    4. 空錯題本顯示明確完成狀態，不產生空白畫面。

  修改前：
    錯題只可在家長頁閱讀，無法從學生端重新作答。

  修改後：
    const questions = createWrongReviewQuestions(getWrongBook(version), selectedKey);
    recordAnswer({ unitId: q.unitId, questionId: q.id, ... });

【測試建議】
  1. 康軒版加入錯題後，首頁顯示題數，進入後可選單題或全部複習。
  2. 翰林版錯題只在翰林版清單出現，不與康軒版互相污染。
  3. 錯題答對後立即移除，wrongFixedCount 增加且每日任務完成。
  4. 錯題再次答錯時保留一筆並更新最新答案。
  5. 空錯題本顯示清楚提示與返回首頁入口。
  6. 完成每日任務後 rewards.stars 仍增加，但所有頁面均不顯示星星。
  7. Firebase 未設定、未登入及已登入同步情境皆維持正常操作。

【後續修正：選擇題型還原】
  問題：第一版錯題複習將所有錯題固定轉為輸入題，造成原本「質數／合數」
        等選擇題要求手動輸入，且無法呈現原本正確選項。
  根因：舊 wrongBook 未保存 type、choices、hint；轉換函式也未依
        版本、單元與 questionId 回查原題庫。
  修正：
    1. 新作答開始保存 type、choices、hint，沿用原 wrongBook 項目結構擴充，
       不影響舊 localStorage 或 Firebase 合併。
    2. 舊錯題依版本、單元與 questionId 回查原題庫，恢復原題型及選項。
    3. 若損壞資料的選項未包含正確答案，安全退回輸入題，避免顯示全部錯誤選項。
    4. 增加新資料、舊資料回查及損壞選項防呆測試。
