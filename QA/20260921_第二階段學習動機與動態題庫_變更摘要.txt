【USER 需求】
  使用者希望將第一版固定十題的展示型數學站升級為更適合每日使用的學習站：
  1. 分數乘法與分數除法題庫需擴充，改為每次隨機出題，並支援難度分級與智慧練習。
  2. 每個單元都要能先閱讀教學，不可只顯示敬請期待。
  3. 首頁需加入每日任務與獎勵機制，提升小朋友每日學習動機。
  4. 家長進度檢視需能看到 XP、星星、徽章、每日任務完成狀態。
  5. 維持純前端、GitHub Pages 可部署，且不可破壞既有 localStorage 學習紀錄。

--------------------------------------------------------------------------------

【影響範圍】

  程式位置一：js/question-engine.js
  函式／區塊：動態題目產生與抽題邏輯
  說明：取代練習頁固定題目清單，提供分數乘法與分數除法動態題庫、難度篩選、智慧練習與避免短期重複出題。
  異動：新增每單元 30 題以上題庫來源，練習時依 difficulty 或 smart 模式抽 10 題並打亂順序與選項。

  修改前：
    練習頁直接使用 data.js 的 QUESTION_BANKS[unitId]，每次固定十題、固定順序。

  修改後：
    selectPracticeQuestions({
      unitId,
      difficulty: selectedDifficulty,
      count: PRACTICE_QUESTION_COUNT,
      recentQuestionIds: getRecentQuestionIds(unitId),
      summary,
    });

  ─────────────────────────────────────────────────────────────────────────────

  程式位置二：js/practice.js、practice.html
  函式／區塊：練習頁初始化、難度選擇、作答回饋與結算
  說明：學生可選擇智慧練習、基礎、進階、挑戰；每次重新出題不固定題目與順序。
  異動：新增難度下拉選單與重新出題按鈕；作答後記錄最近題目、獎勵訊息與每日任務進度；結算可回教學複習。

  修改前：
    const questions = QUESTION_BANKS[unitId];
    renderQuestion();

  修改後：
    questions = selectPracticeQuestions({ unitId, difficulty: selectedDifficulty, count: PRACTICE_QUESTION_COUNT, recentQuestionIds, summary });
    renderQuestion();

  ─────────────────────────────────────────────────────────────────────────────

  程式位置三：lesson.html、js/lesson.js、js/lessons.js
  函式／區塊：教學模式
  說明：提供所有單元可閱讀的教學入口，讓學生可先學習再練習。
  異動：分數乘法與分數除法提供完整教學內容；其他翰林版六年級常見單元提供基礎介紹、概念、步驟、例題、自我檢查。

  修改前：
    未開放題庫的單元僅顯示敬請期待，無可閱讀內容。

  修改後：
    首頁每張單元卡均提供 lesson.html?unit={unitId} 的「先學習／教學模式」入口。

  ─────────────────────────────────────────────────────────────────────────────

  程式位置四：js/rewards.js、js/storage.js
  函式／區塊：每日任務、XP、星星、徽章、稱號與 localStorage 相容升級
  說明：保存學生每日學習動機資料，同時不破壞舊版作答紀錄。
  異動：新增 rewards 資料結構；舊資料讀取時自動補預設值；作答、修正錯題、閱讀教學會更新每日任務與 XP。

  修改前：
    localStorage 僅保存 streak、units、wrongBook。

  修改後：
    localStorage 相容補上 rewards：xp、stars、badges、lessonReads、recentQuestionIds、daily。

【未修改項目】
  1. 後端／資料庫：本專案維持純前端與 GitHub Pages 靜態部署，不新增後端服務或資料庫。
  2. 家長密碼機制：沿用純前端密碼鎖；此機制只能防誤入，無法取代真正的伺服器端驗證。
  3. 既有 localStorage key：仍使用 yue_math_g6_v1，避免舊資料失效；只在讀取時相容補欄位。
  4. data.js 既有 QUESTION_BANKS：保留作相容資料，但練習頁已改用 question-engine.js 出題。

【測試建議】
  1. 首頁確認顯示每日任務、XP、星星、稱號、徽章區塊。
  2. 分數乘法與分數除法分別選 easy / medium / hard / smart，確認每次出題順序不同且題數為 10 題。
  3. 輸入等值分數，例如正解 1/3 時輸入 2/6，確認仍判定正確。
  4. 連續完成 5 題，確認每日任務完成、XP 與星星增加。
  5. 進入任一單元教學頁，按「我讀完了」，確認閱讀任務與 XP 更新。
  6. 將錯題重新答對，確認錯題本移除並推進「修正 1 題錯題」任務。
  7. 家長頁輸入密碼 8888 後，確認能看到 XP、星星、稱號、徽章、每日任務狀態與錯題本。
  8. 使用舊版 localStorage 紀錄開啟網站，確認資料不需清除即可正常顯示並自動補 rewards 欄位。
  9. 執行 node --test tests/，確認所有測試通過。
  10. 部署到 GitHub Pages 後檢查首頁、教學頁、練習頁、家長頁均回應 HTTP 200。
