# 林小玥六年級數學學習站（康軒版為主，翰林版保留）— MVP

一個**完全離線、免後端**的國小六年級數學學習網站。網站預設使用**康軒版**課本目錄，並完整保留**翰林版**的所有內容與學習紀錄，使用者可隨時在首頁切換版本。使用純 HTML / CSS / JavaScript（ES Modules）打造，適合直接部署到 GitHub Pages。

## 功能總覽

- 📚 **教材版本選擇**：首頁上方提供「康軒版 / 翰林版」切換按鈕，**預設康軒版**。切換後會保存到 `localStorage`（若已登入雲端同步，也會一併同步版本偏好），首頁單元卡片、今日任務、教學入口、練習入口與家長進度頁的單元列表都會依所選版本重新顯示；兩個版本的學習紀錄各自獨立累計，互不污染，且切回翰林版時原有紀錄完整可用。
- 🏠 **首頁**：每日挑戰、三個每日任務（完成 10 題練習、閱讀 1 個教學、全部答對或修正錯題）、錯題複習入口、整體學習進度、連續學習天數、XP、徽章、等級稱號與**等級獎品**，以及依目前版本顯示的各單元課程卡片。稱號依等級為：Lv.1～10「玥玥剛出新手村」、Lv.11～30「數學難不倒我」、Lv.31～50「數學小老師」、Lv.51～99「數學天才」、Lv.100 以上「數學大師玥玥」。
- ✖️➗ **已可練習單元**：翰林版「分數的乘法」「分數的除法」、康軒版「第1單元 最大公因數與最小公倍數」「第2單元 分數除法」「第3單元 數量關係」「第4單元 小數除法」（第2單元沿用同一套分數除法動態題庫，但學習紀錄依版本分開累計）使用動態題目引擎，每單元至少 30 題以上，練習時每次隨機抽 10 題，涵蓋選擇題與輸入題，具備：
  - 難度分級：基礎（easy）、進階（medium）、挑戰（hard）
  - 智慧練習：依目前正確率自動選擇適合難度
  - 避免短時間重複出現同一題
  - 立即批改與正確/錯誤標示
  - 提示（Hint）與詳解（解析）
  - 答題進度條與即時正確率
  - 練習結束的結算畫面（答對題數、正確率、單元完成度）
- 📝 **錯題複習**：首頁提供學生可直接進入的錯題複習入口，依目前教材版本列出錯題及所屬單元，可選擇重答單一題目或整份錯題。重新答對會從該版本錯題本移除並計入「修正錯題」每日任務；再次答錯則更新最新答案與日期並保留。錯題本為空時顯示明確完成提示。資料仍沿用既有版本化 `wrongBook` 結構，可與舊 localStorage 及 Firebase 合併資料相容。
- 📖 **教學模式**：所有單元卡片都有「先學習／教學模式」入口。分數乘法、分數除法與康軒第1～4單元提供概念、步驟、常見錯誤、例題解析、自我檢查；康軒版第5～9單元與複習（一）（二）（依課本目錄建立，僅列出單元／小節標題，不含課本文字或題目）與翰林版其他單元皆提供學習目標與小節重點的基礎教學導覽，避免只顯示敬請期待。
  - ✅ **自我檢查改為勾選制**：每個自我檢查項目都是一個 checkbox，**必須全部勾選**才能啟用「我讀完了」按鈕；未勾完前按鈕維持 disabled 無法送出。點下「我讀完了」才會記錄該單元教學閱讀完成；若當日尚未完成閱讀任務，會一次取得該任務的 25 XP。若單元沒有自我檢查項目（例如未來新增單元忘記設定），會自動視為可直接完成，不會卡住使用者。每次重新載入教學頁，勾選框都會重置為未勾選（避免誤顯示「本次已完成」），但只要**曾經**完成過這個單元的自我檢查，頁面上方會顯示「已完成過」提示，方便複習。
- 🚀 **每日任務與獎勵**：三個每日任務固定為「完成 10 題練習」（50 XP）、「閱讀 1 個教學」（25 XP）、「全部答對或修正錯題」（25 XP）——今天只要有一次練習全部答對，或是從錯題複習把任一錯題重新答對，兩者任一即可完成第三項；每項任務同一天只會獎勵一次。三項合計 100 XP，依每級 100 XP 的規則，當天完成全部任務剛好升一級。星星欄位與每日任務累加邏輯仍完整保留，以維持舊 localStorage／Firebase 資料相容，但目前所有學生與家長畫面皆不顯示星星數字、圖示或文案。
- 🎁 **等級獎品（零用錢里程碑）**：每 10 級一個獎品里程碑（Lv.10～100），10～40 級與 60～90 級各為零用錢 100 元，**Lv.50 與 Lv.100 為零用錢 500 元**；達到 100 級為目前最高里程碑，會顯示「目前最高獎勵里程碑為 100 級」。里程碑是否**解鎖**依目前等級即時判斷；是否**已確認發放**則由家長在家長頁（需先通過 8888 密碼）按下「確認領取」才會標記，代表零用錢已實際交給孩子——**小朋友端無法自行標記已領取**，避免誤操作。首頁在「每日任務與獎勵」卡片的徽章清單下方提供「🎁 查看等級獎品」按鈕，點擊後以彈出視窗（手機上會以底部抽屜樣式顯示）呈現完整 10 個里程碑清單、目前等級與距離下一個獎品還差幾級，可用關閉按鈕、點擊視窗外側或按 Esc 關閉，不會在首頁直接展開佔用版面。家長頁另外顯示累計已解鎖金額與已確認發放金額，達成新里程碑時會有明確的鼓勵提示文字。
- 💾 **本機學習紀錄**：使用 `localStorage` 保存各單元作答次數、正確率、完成度、連續學習天數、錯題本、最近出題記錄、教學閱讀紀錄與獎勵資料。學習進度依「教材版本＋單元」分開儲存；連續學習天數與 XP／徽章／每日任務則為兩個版本共用（代表整體學習動機，不分版本）。為向下相容而保留的 `rewards.stars` 也會繼續累加及同步，但不在 UI 顯示。所有資料**只存在使用者瀏覽器**，不會上傳到任何伺服器。
- 👨‍👩‍👧 **家長進度檢視頁**（`parent.html`）：預設家長密碼為 `8888`，驗證通過後才能查看學習天數、最近學習日期、各單元作答狀況、完整錯題本（含解析）、XP、稱號、徽章、每日任務狀態、**等級獎品清單與「確認領取」按鈕**（僅密碼驗證後可操作，累計顯示已解鎖／已確認發放金額），以及使用具二次確認的「清除所有學習紀錄」功能。家長頁也可切換檢視版本，會顯示對應版本的單元列表與錯題本。頁面上方一律顯示目前雲端同步狀態（離線／已登入哪個帳號），不需密碼即可看到，方便家長快速確認裝置狀態。
- ☁️ **選用的雲端同步（第三階段）**：可選擇性設定 Firebase（Auth + Firestore），讓親子在不同電腦用同一組帳號登入後看到同一份學習進度，教材版本偏好、各版本進度資料與**等級獎品的已解鎖／已確認里程碑**都會一併同步（合併採聯集，不會因為登入而遺失任一裝置已確認的獎品紀錄）。**這是純粹的加分功能**：不設定、未登入、離線或 Firebase 發生任何錯誤時，網站會自動且安全地退回目前的 localStorage 離線模式，首頁／練習／教學／獎勵／家長頁（含 8888 密碼鎖）都與離線版完全一致，不會出現任何錯誤畫面。詳細設定步驟見 [`FIREBASE_SETUP.md`](./FIREBASE_SETUP.md)。

## 本機執行方式

本站為純靜態網站，但由於使用了 ES Modules（`<script type="module">`），瀏覽器基於安全性限制，**不允許直接以 `file://` 方式開啟 index.html**，需要透過本機伺服器：

**方式一：使用 Python（大多數環境已內建）**

```powershell
cd 專案資料夾
python -m http.server 8080
```

然後開啟瀏覽器造訪 <http://localhost:8080/>

**方式二：使用 Node.js**

```powershell
npx serve .
```

**方式三：使用 VS Code 的 Live Server 擴充套件**

在 `index.html` 上按右鍵選擇「Open with Live Server」。

## 執行測試 / Build 驗證

專案不需要任何建置流程（沒有打包器、沒有 npm 相依套件），但提供了 Node.js 內建測試框架（`node --test`）驗證核心邏輯（分數解析、批改、正確率、連續學習天數、單元進度、錯題本合併與 localStorage 紀錄）：

```powershell
npm test
# 或直接：
node --test tests/
```

目前測試涵蓋分數判定、localStorage 相容、教材版本切換與版本化進度資料、題目隨機/難度篩選、獎勵進度、教學閱讀紀錄、自我檢查勾選制（全部勾選才能完成、部分勾選不可完成、空清單安全處理）、每日任務規則（單題不直接發 XP／星星、三項任務固定 50／25／25 XP、完成全數任務剛好取得 100 XP 並升一級、完成 10 題練習、全部答對或修正錯題二選一達成、同日不重複發獎）、等級稱號邊界（Lv.1／10／11／30／31／50／51／100）、**等級獎品里程碑（金額計算、解鎖判定、家長確認領取、重複確認防呆、與 Firebase 合併時的聯集規則）**、**帳號同步收合 UI 決策邏輯（已同步顯示精簡卡片、錯誤/未登入強制完整表單、登出回復預設狀態）**、**首頁標記結構檢查（等級獎品入口位置、彈出視窗預設隱藏、學生端無家長確認控制項）**、家長密碼邏輯，以及第三階段的 Firebase 設定偵測與雲端資料合併規則（含版本偏好合併）。雲端同步測試全程使用假資料驗證純函式邏輯，**不會連線到真實 Firebase**，因此在沒有網路或沒有 Firebase 專案的環境下也能正常執行。

另新增錯題複習回歸測試，涵蓋單題／整份重答、答對移除、答錯更新、康軒／翰林版本隔離與空錯題本；並驗證每日任務完成後內部 `rewards.stars` 仍正確累加，但首頁、練習頁及家長頁的可見內容不含星星文字或圖示。

## 雲端同步（選用功能）

第三階段加入了「選用的」Firebase 雲端同步，讓親子可以在不同電腦用同一組帳號登入後看到同一份學習進度。重點原則：

- **離線優先**：完全不設定 Firebase 也能正常使用全部功能，這是預設狀態。
- **優雅回退**：只要沒有設定、設定不完整、網路不通或 Firebase 發生任何錯誤，網站一律安全退回目前的 localStorage 離線模式，不會出現錯誤畫面，首頁會顯示「離線模式，尚未設定雲端同步」。
- **不覆蓋、不遺失**：登入時會把本機與雲端資料「合併」而非覆蓋——單元進度取較大值、已完成題目取聯集、錯題本與徽章取聯集、連續天數與每日任務取較新/較大值。
- **狀態透明**：首頁「帳號與雲端同步」卡片與家長頁上方的同步狀態列，隨時顯示目前是離線、已登入、同步中還是發生錯誤。首頁在**已登入且成功同步過**之後，會把完整登入表單收合成一行精簡卡片（顯示遮蔽後的帳號、最近同步時間），並提供「⚙️ 管理帳號與同步」按鈕可隨時展開完整表單（例如登出）；未設定 Firebase、尚未登入或同步發生錯誤時，一律維持完整表單與明確錯誤訊息，不會被誤縮起來，登出後也會自動回復成完整登入表單。
- 完整設定步驟（建立 Firebase 專案、啟用 Email/Password、建立 Firestore 與安全規則、部署注意事項）請見 [`FIREBASE_SETUP.md`](./FIREBASE_SETUP.md)。

## 部署到 GitHub Pages

1. 將本專案推送到 GitHub repository（例如 `linyufu0519/YUE-Learning`）。
2. 到 GitHub repository 的 **Settings → Pages**。
3. 在 **Build and deployment** 選擇 **Source: Deploy from a branch**。
4. **Branch** 選擇要發佈的分支（例如 `main`）與資料夾 `/ (root)`，儲存。
5. 等待數分鐘後，即可透過 `https://<使用者名稱>.github.io/<repo名稱>/` 造訪網站。

### 部署注意事項

- 本站所有連結皆使用**相對路徑**（例如 `css/styles.css`、`js/data.js`、`practice.html?unit=...`），無論部署在 repo 根目錄或子路徑下皆可正常運作，不需額外設定 `base` 路徑。
- 若要發佈非 `main` 分支的內容，請先建立 Pull Request 合併到指定的發佈分支，或直接調整 GitHub Pages 設定中選擇的分支。
- 學習紀錄與錯題本儲存在使用者「當次瀏覽器」的 `localStorage`：
  - 換裝置、換瀏覽器或清除瀏覽器資料都會導致紀錄消失（若已設定並登入 Firebase 雲端同步則不受影響）。
  - 舊版紀錄會自動補上第二階段新增的 `rewards`、教學閱讀與最近出題欄位，不需要手動清除資料。
  - 本次新增教材版本功能後，舊資料會自動視為翰林版進度並保留完整內容；教材版本偏好預設為康軒版（不影響舊資料本身）。
- GitHub Pages 為純靜態託管，不需要任何伺服器端設定或環境變數。
- 家長專區預設密碼集中定義於 `js/parent-auth.js` 的 `DEFAULT_PARENT_PASSWORD`，預設值為 `8888`。這是離線純前端的防誤入機制，密碼可從網站原始碼查到，不能取代後端身分驗證；若需要真正的存取控制，必須導入後端驗證。
- 雲端同步的 `js/firebase-config.js` 已列入 `.gitignore`，一般 `git push` 不會把真實金鑰帶到遠端；若要讓正式部署的 GitHub Pages 也能使用雲端同步，需要額外操作，詳見 `FIREBASE_SETUP.md`「步驟六」。未做這一步時，正式站台會維持離線模式，功能完全不受影響。
